01 / VISION

不是暗网，不是 DAO，
不是去中心化的 Discord。

Havix 是去中心化对等网络协议，用于验证社会学论文《底层高认知者的结构性困境》中提出的"分层自组织网络"假设。

当主流集权系统的资源抽水比例过高、内卷失控时，高认知个体可以通过构建平行网络实现生存与意义的自我维系。Havix 是这一主张的技术验证载体——不推翻，但绕开。

"集权系统的反面不是无政府，是分层可见性 + 准入自治。完全开放的乌托邦才是社会学上不成立的。"

— Havix 设计哲学

03 / ARCHITECTURE

四层协议栈

从底层传输到应用寄生，每一层职责清晰。应用层不直接使用传输层，必须经过身份层与协议层。

▸ 应用层（寄生）
维基 SPA · 市场 SPA（任意）· 私聊隧道 · CLI 可视化
▸ 身份层
主 DID → context 派生（A/B/C/D）· HKDF 不可关联
▸ 协议层（公共 / 私域）
维基协议 · 市场协议 · Offer/Credit · Vouch/Slash
▸ 经济层
Reputation(累积) ⇄ Credit(可消耗) · Faucet 冻结等额信誉 · 5 人临时仲裁团 → slash 50 赔 + 50 金库
▸ 传输层
libp2p · gossipsub · 单跳 relay（概率轮换 20%/epoch）· IPFS · noise E2E · 电路硬切换

双平面隔离

可见性在协议层硬性切分，不靠加密兜底。私域 CID 绝对不进 DHT，只在私有 topic 内分发。

PRIVATE PLANE

私域平面

  • 私有 gossipsub topic
  • topic 名 = sha256(邀请令牌)
  • 消息体 = 令牌派生密钥再加密
  • 市场 SPA 分发
  • 私聊电路协商
  • Credit 流水
PUBLIC PLANE

公共平面

  • gossipsub mesh（邻居发现、心跳）
  • KadDHT（仅维基 CID 寻址）
  • Rendezvous（跨网段发现）
  • mdns（局域网自动发现）
  • 公开广播、维基读取
04 / MECHANISMS

四个核心机制

每一处都对得上论文主张。这是社会学命题在协议层的可验证实现。

Ⓐ

4-Context DID 派生

主 DID 派生 4 个不可关联的子身份：A 公开畅游、B 市场、C 私聊、D 维基编辑。同一节点在不同场景下使用不同身份，外部观察者无法关联。

Ⓑ

Reputation-Credit 双轨

高信誉节点签发 Credit 时冻结等额自身信誉。每张 Credit 都有对应冻结的信誉背书，不能凭空印。作恶则 slash 冻结部分。

Ⓒ

临时仲裁团

5 个高信誉节点随机抽取，排除 vouch 关联防串谋。多数裁决，slash 50% 赔受害者、50% 进金库。治理不是投票，是行会自治。

Ⓓ

单跳 Relay + 多链路对冲

3 条并行 relay 各传 1/3 流量。单个 relay 被攻破只能看到片段。relay 由高信誉节点承担，作恶会损失长期信誉——用信誉换延迟。

05 / ECONOMY

信誉即货币

不用真钱。真钱会引入交易所这个中心化漏洞，违背去中心化主张。Havix 用信誉本身作为发行凭证的锚定物。

▸ Faucet 机制
高信誉节点 Alice (rep=80) → 签发 10 credit 给 Bob
→ Alice 信誉冻结 10，可用 70，冻结 10
→ Bob 获得 10 credit（可消费任何 offer）
→ Bob 消费 credit → Alice 冻结部分释放
↓ 如果纠纷
▸ Slash 机制
Bob 付了 credit 但 Carol 没交付 → 发起 arbitration
→ 仲裁团调查 IPFS 上的 credit 流水
→ 裁决 guilty → Carol 冻结部分释放给 Bob（50%）+ 进金库（50%）
→ 治理不武器化：slash 只动冻结部分，不动可用信誉

"高认知个体不需要法定货币，他们自身的认知信誉就是发行凭证。S 国的资源抽水在这里失效——因为你抽的不是钱，是 peer-to-peer 的信用关系。"

— Havix 经济模型论证
06 / TOPOLOGY

混合拓扑

不是纯 DHT，不是中心化网络。Gossip Mesh + Rendezvous + 门控 KadDHT 的混合形态。

①

局域网 mdns

同子网节点自动发现，无需配置。开发与本地测试的默认机制。

②

Rendezvous 跨网段

由高信誉节点自愿承担 rendezvous point。准入门槛与 relay 复用：动态阈值（前 30%）+ 3 vouch。无固定 bootstrap。

③

门控 KadDHT

仅公共维基 CID 进 DHT。私域市场 CID 绝对不进 DHT。门控在协议层硬编码：if (privateCid) throw。

④

双平面隔离

同一组节点，两个平面。私域流量走私有 topic，公共流量走 mesh。可见性在协议层硬切分。

07 / ECOSYSTEM

私域生态

Havix 不定义应用，只定义协议。每个私域市场 = 一个 App，通过 manifest 声明能力需求。S 网络本身不知道它托管了什么应用。

▸ Havix Protocol Spec
协议规范，语言无关。JS 是第一个参考实现，未来可有 Rust/Go/Python 实现。
▸ Havix App Manifest
name / version / capability / permissions / invite_token_format / spa_cid / min_reputation / trust_weight
每个市场是一个 App，第三方开发者可写新 App。
▸ Reputation Portability
主 DID 信誉 = Σ(context 信誉 × App 权重)
翻译市场(0.8) + 教学市场(0.5) + 维基编辑(1.0) → 主 DID 全局信用
→ 跨场景准入凭证

FW-01（推迟）：App 信任权重审核采用"自然涌现"方案——权重不由谁指定，而是通过"被多少高信誉节点使用"动态计算。阶段一无第三方 App，不存在刷分问题。

08 / ROADMAP

MVP 八里程碑

每个里程碑独立可演示。不依赖后续里程碑，不推翻前步。按顺序推进，不并行。

M1
TRANSPORT

双平面传输基线

plaintext → noise，初始化双平面。KadDHT 门控，rendezvous client。

▸ 双节点 mdns 自动发现 + 跨网段 rendezvous 连接
M2
IDENTITY

4-Context DID 派生

HKDF 派生 A/B/C/D 四个不可关联子身份。主 DID = ed25519 私钥哈希。

▸ 4 个子 DID 不可关联（密码学验证）
M3
WIKI

维基协议

CID 广播 + 编辑员签名校验。编辑员资格 = N 个高信誉节点 vouch 累积到阈值。

▸ 维基条目发布、签名校验、无资格写入被拒
M4
ECONOMY

Credit 双轨

Faucet + 冻结账本。Credit 凭证 = IPFS 上的签名 JSON。消费时 nonce 公开作废。

▸ Credit 流水 IPFS 链上追溯
M5
RELAY

单跳 Relay + 多链路对冲

libp2p stream + noise + 单跳 relay。准入：动态阈值 + 3 vouch。轮换：20%/epoch。

▸ 3 条并行 relay 各传 1/3 流量，单点泄露只看到片段
M6
GOVERNANCE

临时仲裁团

5 个高信誉节点随机抽取，排除 vouch 关联。多数裁决，slash 50 赔 + 50 金库。

▸ 完整仲裁流程跑通，slash 自执行
M7
PRIVATE

邀请制市场

令牌签发 + 私有 topic + SPA 拉取。topic 名 = sha256(令牌)，消息体双重加密。

▸ 私域不可见性通过 traffic analysis 验证
M8
INTEGRATION

CLI 收口 + 集成测试

命令补全、信誉持久化、4 节点集成测试。完整场景跑通：组网 → 维基 → offer → 仲裁 → 隧道 → 市场 → 自愈。

▸ 原规格所有测试步骤 1-6 通过
